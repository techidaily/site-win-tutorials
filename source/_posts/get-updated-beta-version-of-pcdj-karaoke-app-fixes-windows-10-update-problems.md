[Karaoki](https://tools.techidaily.com/pcdj/products/) public beta build 0.9.7510 is ready for download. This new free update and maintenance release addresses some issues related to a recent Windows 10 update and changes to Direct X. The issue caused various problems, most notably (in some cases) causing Karaoki to not load at all.

If you’re running Windows 10 Update KB4556799 or higher you will want to install this free update immediately. The audio engine has been upgraded to support the changes in the recent Windows 10/DirectX updates. Karaoki should open and run smoother in general on Windows 10 than the prior iterations.

The Karaoki development team is working on a number of other improvements and feature upgrades that we plan to release soon.
